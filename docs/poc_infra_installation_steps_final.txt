## GBS Service Health Dashboard — Environment Setup

---

```
PREREQUISITES CONFIRMED
-----------------------
- RDP access to VM via AVD session
- IIS installed with URL Rewrite 2.1 and ARR 3.0
- ARR proxy enabled at server level
- MS SQL on separate VM, SQL Server Authentication enabled
- gbs_app login created, gbs_health database initialised via init.sql
- Port 3000 open inbound from AVD subnet
```

### STEP 18 — Configure IIS Site

```

   Site name  : gbs-dashboard
   Physical path: C:\Users\karthikr\gbs\gbs-poc\frontend\dist

   icacls "C:\Users\karthikr\gbs\gbs-poc\frontend\dist" /grant "IIS_IUSRS:(OI)(CI)R" /grant "IUSR:(OI)(CI)R" /T
```

---

### STEP 19 — Enable ARR Proxy

```
In IIS Manager:
   Click the server node (machine name, top level)
   Double-click: Application Request Routing Cache
   Click: Server Proxy Settings (right panel)
   Check: Enable proxy
   Click: Apply

Or via PowerShell (Administrator):
   Set-WebConfigurationProperty `
       -pspath 'MACHINE/WEBROOT/APPHOST' `
       -filter 'system.webServer/proxy' `
       -name 'enabled' `
       -value 'true'

Then:
   iisreset
```
